# PEWAM — project page

Project page for **Keep the Effect, Drop the Actor: Programmable Effect-to-Execution World-Action Models**
by Junyi Hu, Zhewen He and Yi Fang (New York University Abu Dhabi).

**→ https://junyi2005.github.io/pewam/**

The page hosts the paper, the method overview, the results and the supplementary video.
This repository contains the project page only; no code or model weights are released here.
